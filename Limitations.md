# CyberTrace – Project Limitations

| ID | Limitation | Future Improvement |
|---|---|---|
| L-01 | Limited log file formats are supported | Add support for more log formats |
| L-02 | Malformed log entries may not be fully processed | Improve input validation |
| L-03 | Risk assessment uses predefined rules | Introduce configurable detection rules |
| L-04 | Investigation is limited to available log data | Support additional data sources |
| L-05 | Automatic alert notifications are limited | Implement real-time alert notifications |
| L-06 | Reports contain limited information | Add customizable report formats |
| L-07 | Large log files may affect performance | Optimize log processing |
| L-08 | Investigation history may not persist between sessions | Add persistent storage |
